## Функциональность

### Пользователь
- Регистрация и вход
- Просмотр списка кампаний (карточки + поиск)
- Просмотр деталей кампании
- Создание своей кампании
- Совершение пожертвования
- Просмотр своих пожертвований и кампаний
- Профиль и смена пароля

### Администратор (роль Admin)
- Управление пользователями (поиск, фильтр, блокировка, удаление)
- Управление кампаниями (поиск, фильтр, удаление)
- Просмотр всех пожертвований
- Статистика (карточки + топ кампаний)
- Экспорт в Excel (.xlsx)

### Безопасность
- Хэширование паролей (SHA256 + соль)
- Счётчик неудачных попыток входа
- Капча после 3 неверных попыток
- Запись истории входов
- Смена пароля

## Установка и запуск

### 1. База данных

1. Откройте **SQL Server Management Studio**
2. Выполните скрипт [`create_up1.sql`](create_up1.sql)
3. Убедитесь, что база `up1` создана и заполнена

### 2. Строка подключения

В файле `App.config` укажите свой сервер:

```xml
<connectionStrings>
  <add name="DonationDb"
       connectionString="Data Source=.\MSSQLSERVER01;Initial Catalog=up1;Integrated Security=True;TrustServerCertificate=True"
       providerName="System.Data.SqlClient" />
</connectionStrings>
```

Имя сервера замените на своё (например `.\SQLEXPRESS` или `(local)`).

### 3. Запуск приложения

1. Откройте решение `Cursavayaup1.sln` в Visual Studio
2. Восстановите NuGet-пакеты (ClosedXML, EntityFramework)
3. Соберите и запустите проект (`F5`)
